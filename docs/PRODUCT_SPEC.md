# CIA Print 商品仕様

## 目的

iPad上のブラウザから、参加者に印刷設定やOSの印刷ダイアログを操作させず、決められた資料を印刷するための専用画面を提供する。

## 確定動作

- 最初にプリンターのホーム画面を表示し、参加者がタップするとロック案内を経てパスワード入力画面を表示する。
- パスワード照合中の表示は、通信が速い場合でも読み取れる最低表示時間を設ける。
- 不正解時は一般的なパスワード画面と同様に「パスワードが間違っています。」と表示する。
- 正解後だけ印刷ボタンを表示する。
- 参加者が変更できる印刷設定は置かない。
- 主操作は「照合する」と、認証後の「印刷する」とする。
- 処理中はボタンを無効化し、二重送信を防ぐ。
- 送信中、受付完了、失敗を日本語で明示する。
- 受付完了から設定秒数後、パスワードを破棄してプリンターのホーム画面へ戻る。
- iPad横画面でスクロールせず1画面に収まることを基本とする。
- 管理画面からパスワード、管理PIN、待機時間、プリンター名を変更できる。
- 管理画面から固定PDFの差し替えと1部再印刷ができる。

## 印刷方式

- iPad Safariから同一LAN内のMacへ印刷指示を送る。
- Macは固定PDFをmacOS CUPS経由でEW-M634Tへ1部だけ送る。
- 参加者へ印刷ダイアログ、PDF選択、部数、用紙設定を表示しない。
- 受付成功時は物理的な完了と断定せず、用紙が出るまで待つよう案内する。

## 印刷資料

- 部数は1部に固定する。
- 本番PDFが確定するまでは接続確認専用PDFを使用する。
- 管理画面でアップロードしたPDFはリポジトリ内の管理用ファイルへ置き換える。

## デザインと操作

- 参加者画面と管理画面は、白を基調にしたプリンター操作パネルらしい外観とする。
- 装飾目的の枠やフレームを多用せず、余白、区切り線、文字サイズとウェイトで情報の優先順位を示す。
- アイコンはGoogle公式Material Symbols Roundedを使用し、イベント中のオフライン動作に備えて必要な字形だけをローカル配信する。
- 主要ボタンは十分なタップ領域と明確な押下状態を持たせ、Apple Human Interface Guidelinesのアクセシビリティと操作原則を基準にする。
- 色だけに依存せず、日本語の状態文とアイコンを併用して送信中、成功、失敗を示す。
- 参加者画面はヘッダーや説明的な文章を置かず、白い1画面にアイコン、パスワード入力、現在必要な操作だけを表示する。
