# CIA Print 商品仕様

## 目的

iPad上のブラウザから、参加者に印刷設定やOSの印刷ダイアログを操作させず、決められた資料を印刷するための専用画面を提供する。

## このフェーズで確定すること

- 参加者が変更できる設定は置かない。
- 用紙、カラー、印刷面、部数は確認情報としてのみ表示する。
- 主操作は「印刷する」の1つとする。
- 処理中はボタンを無効化し、二重送信を防ぐ。
- 送信中、印刷中、完了、失敗を日本語で明示する。
- iPadで1画面に収まることを基本とする。

## 管理画面

- `/admin` に参加者画面と分離した管理画面を置く。
- Epson Connect APIが未設定、未認証、オフライン、オンラインのどれかを明示する。
- 製品名と末尾だけを残したシリアル番号を表示する。
- Epsonの機器認証、再確認、接続解除、固定A4資料のテスト印刷を提供する。
- 管理PINが設定されている場合だけPIN入力を要求する。
- 認証情報や完全なシリアル番号を画面へ表示しない。

## テスト印刷

- A4、普通紙、白黒、片面、1部で固定する。
- 接続確認専用PDFを印刷し、参加者向け資料はまだ送信しない。
- 二重送信を防ぎ、送信結果とジョブIDを管理画面に表示する。

## 次フェーズ

- 実機テスト完了後、参加者画面の「印刷する」を実ジョブへ接続する。
- 管理者向け再印刷、用紙切れ、インク切れ対応
- 実際に印刷するPDFまたは画像の確定
