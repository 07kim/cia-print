# CIA Print アーキテクチャ

## 境界

- 参加者画面は固定資料の印刷操作だけを提供する。
- `/admin` は端末設定、PDF・写真の差し替え、管理者再印刷を提供する。
- 本番印刷画面とAPIはMac上の`local_server.py`から配信する。
- オンライン版はローカル版と同じ参加者認証、`admin0000`による管理画面遷移、画面遷移を確認できるが、印刷受付はデモ動作とし実機へは送信しない。
- オンライン版の管理画面から変更した参加者パスワードと印刷資料を端末間で永続共有するには、Vercelとは別の永続保存先が必要である。保存先を接続するまではローカル版だけを本番設定の正とする。
- iPad、Mac、プリンターは同一LAN内で通信する。
- Epson Connectのアカウント、API、OAuth、インターネット接続を必要としない。
- 初期印刷物はリポジトリ内のPDFとして管理し、管理画面から差し替えたPDF・PNG・JPEGはローカルファイルとして管理する。
- UIアイコンは`assets/fonts/material-symbols-rounded-subset.ttf`として必要字形だけを同梱し、外部フォント配信へ依存しない。

## ローカル印刷

1. iPadが`POST /api/unlock`へパスワードを送る。`admin0000`ならトークンを発行せず管理画面へ分岐し、参加者パスワードなら同じ接続元で60秒間だけ有効な一時トークンを受け取る。
2. 正解時だけ印刷操作を表示し、`POST /api/print`へ一時トークンを付けて要求する。
3. Macは一時トークンを印刷要求時に1回で無効化し、同時処理ロックとクールダウンを確認する。
4. `lp -d <printer> -n 1 <fixed-pdf>`を引数配列で実行する。
5. CUPS受付後、iPadは設定時間だけ受付結果を表示し、プリンターのホーム画面へ戻る。

## 運用

- `scripts/start_local.sh`はプリンター初期設定、`caffeinate`、サーバー起動を続けて実行する。
- `scripts/setup_printer.sh`は、登録済みの`EPSON_EW_M634T_Series`を優先し、未登録時だけ同一LAN上のEW-M634TをBonjour/IPPで検出して、ドライバーレスのAirPrint/IPPプリンターとして登録する。
- 検出結果にBonjourと直接IPPが併存する場合はBonjourを優先する。直接IPPは`.local`ホストまたはIPアドレスを持つ解決可能な形式だけを候補にし、裸の機器名を持つ不完全なURIは登録しない。
- 自動登録の対象はEW-M634Tだけとする。未検出または複数候補の場合は別機種を登録せず、手動追加の案内を表示してサーバー起動は続ける。
- 通常起動で登録に管理者権限が必要な場合だけパスワード入力を求める。Macログイン時の自動起動では入力待ちにせず、既存の登録状態で起動する。
- サーバー起動時に、前回からCUPSへ残っている対象プリンターの印刷待ちを取り消す。
- 印刷要求の前後にCUPS上の登録状態と既知の停止・オフライン状態を確認し、確認または送信に失敗した場合はジョブを取り消して成功応答を返さない。
- 既に同じポートでCIA Printが起動している場合は二重起動で異常終了せず、既存プロセスを利用する案内を表示する。
- 新しく受け付けた印刷も60秒以内に完了しない場合はジョブ単位で取り消し、後日の再接続で排紙しない。
- `scripts/install_autostart.sh`はユーザーのLaunchAgentを作成し、Macログイン時に起動する。
- `admin0000`と参加者パスワードはイベント運用用の画面分岐であり、強固なネットワークセキュリティではない。管理画面に別の管理PINは設けない。

## 制約

- Macを起動し、スリープを防止してローカルサーバーを動かし続ける必要がある。
- LANが端末同士の通信を禁止している場合は利用できない。
- CUPS受付後の物理的な排紙完了はブラウザから確定しない。
