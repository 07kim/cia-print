# CIA Print 画面遷移

## 参加者フロー

1. プリンターのホーム画面を表示する。
2. プリンターをタップすると、ロック案内を短く表示し、アイコンが上へ抜ける動きでパスワード入力へつなぐ。
3. パスワード送信後は最低1.2秒「照合しています…」を表示する。
4. 不正解なら同じ画面で「パスワードが間違っています。」と表示する。
5. 正解なら「プリンターに接続しています…」と進行バーを約5秒表示し、印刷画面へ進む。
6. 印刷ボタンを押すと実際の印刷要求を送る。受付が早くても送信中画面を約6秒表示する。
7. 受付成功後は受付完了を表示し、20秒後にパスワードと印刷許可を破棄してプリンターのホーム画面へ戻る。
8. 失敗時はエラー画面を表示し、戻る操作でプリンターのホーム画面へ戻る。

## リセット規則

- 認証後60秒以内に印刷されなければ、印刷許可を破棄してホームへ戻る。
- 再読み込みや再接続では以前の印刷許可を復元しない。
- 受付完了からホームへ戻る際は、結果カードを画面から隠した後に表示状態を初期化し、中間状態を一瞬表示しない。
