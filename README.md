# CIA Print 起動ガイド

この文書だけで、初めて担当する人がGitHubからシステムを準備し、Mac・iPad・EPSON EW-M634Tを接続して印刷端末を立ち上げられることを目的とします。

## 担当別：ここだけ見ればOK

### Mac担当者

「ターミナル」を開き、次の1行を貼り付けてReturnキーを押します。初回も2回目以降も同じです。

```sh
cd ~/Desktop && if [ -d cia-print/.git ]; then git -C cia-print pull --ff-only; else git clone https://github.com/07kim/cia-print.git; fi && cd cia-print && ./scripts/start_local.sh
```

- 終了：`Control + C`

#### この1行で自動になること

- CIA Printの取得または更新
- MacのIPアドレス確認
- 印刷待ちの整理
- スリープ防止
- CIA Printの起動
- iPadで開く参加者画面・管理画面URLの表示

#### 最初の1回だけ人が行うこと

- Mac・iPad・EW-M634Tを同じWi-Fiへ接続する
- EW-M634TをMacの「プリンタとスキャナ」へ追加する
- macOSの権限確認や管理者パスワードが表示された場合は承認する

プリンターのWi-Fi設定やmacOSの初回許可は、セキュリティ上、ターミナルの1行だけで完全に省略できません。EW-M634Tを一度Macへ追加した後は、通常は上の起動用1行だけで開始できます。

将来、プリンターの自動検出・自動登録を追加する場合も、見つからないときに勝手なプリンターを登録せず、「3台を同じWi-Fiへ接続してください」と表示して停止する設計にします。

### iPad担当者

Macのターミナルに表示された「参加者画面」のURLをSafariへ入力します。

```text
参加者画面  http://192.168.75.237:8765/
```

数字は例を写さず、Macに表示されたURLを使ってください。

### 管理担当者

Macのターミナルに表示された「管理画面」のURLをSafariへ入力します。

```text
管理画面  http://192.168.75.237:8765/admin/
```

## 詳しい接続手順

### 1. 3台を同じWi-Fiへつなぐ

次の3台を、必ず同じWi-Fiまたは同じスマートフォンのテザリングへ接続します。

- Mac
- iPad
- EPSON EW-M634T

#### テザリング名とパスワードのおすすめ

プリンター側では、日本語や一部の記号を含むテザリング名が見つからない場合があります。テザリングに使うスマートフォンのデバイス名・ネットワーク名は、半角英数字だけにしてください。

おすすめの例：

```text
ネットワーク名: print
パスワード: qqqqqqqq
```

ネットワーク名は`print`のような短い半角英字で構いません。EW-M634Tではパスワードを矢印キーで入力するため、長く複雑な文字列は当日の設定ミスにつながります。イベント専用テザリングでは、`qqqqqqqq`のように同じ半角英字を連続させた、入力しやすい8文字以上のパスワードがおすすめです。普段使用する個人用Wi-Fiや重要なネットワークでは、推測しやすいパスワードを使用しないでください。

### 2. Macで起動する

`command + space`を押し、`ターミナル`と入力して開きます。

上の「Mac担当者」にある1行を貼り付け、Returnキーを押します。

```sh
cd ~/Desktop && if [ -d cia-print/.git ]; then git -C cia-print pull --ff-only; else git clone https://github.com/07kim/cia-print.git; fi && cd cia-print && ./scripts/start_local.sh
```

初回は取得、2回目以降は更新を自動で行います。`.command`ファイルの操作は不要です。

### 3. ターミナルに表示されたURLを見る

起動すると、次のような表示が出ます。IPアドレスは毎回同じとは限りません。

```text
================================================================
 CIA PRINT を起動しました
================================================================

 iPadのSafariに、次のURLをそのまま入力してください:

   参加者画面  http://192.168.75.237:8765/
   管理画面    http://192.168.75.237:8765/admin/
```

数字は例を写さず、必ずそのMacに表示されたURLを使います。

### 4. iPadで開く

1. iPadでSafariを開く。
2. 画面上部のアドレス欄をタップする。
3. ターミナルの「参加者画面」のURLをそのまま入力する。
4. キーボードの「開く」を押す。
5. プリンターのホーム画面が表示されたら接続成功。

### 5. 終了する

Macのターミナルで`Control + C`を押します。

## 1. 必要なもの

- macOSを搭載したMac 1台（印刷中継・Webサーバー）
- iPad 1台（参加者操作画面）
- EPSON EW-M634TとA4用紙
- MacとiPadとプリンターを接続できる同一ネットワーク
- 初回ダウンロード時のみGitHubへアクセスできるインターネット

本番中のEpson Connect、Vercel、外部API、インターネット接続は不要です。3台が同じローカルネットワーク内で相互通信できることが必要です。

## 2. ネットワークを作る

最も分かりやすい構成は、1台のスマートフォンのテザリングまたは専用Wi-Fiルーターへ、Mac・iPad・プリンターの3台を接続する形です。

1. テザリング端末でインターネット共有を有効にする。
2. ネットワーク名（SSID）とパスワードを確認する。
3. MacをそのSSIDへ接続する。
4. iPadを同じSSIDへ接続する。
5. EW-M634TのWi-Fi設定から同じSSIDへ接続する。

一部の公共Wi-FiやゲストWi-Fiは端末同士の通信を禁止します。その場合はテザリングか専用ルーターへ切り替えてください。

## 3. GitHubからMacへ入れる

### Gitを使う

Macの「ターミナル」を開き、保存したい場所で実行します。

```sh
git clone https://github.com/07kim/cia-print.git
cd cia-print
```

後日更新を受け取る場合は、同じフォルダーで`git pull`を実行します。

### ZIPで入れる

1. GitHubの`07kim/cia-print`を開く。
2. 「Code」→「Download ZIP」を選ぶ。
3. ZIPを展開し、移動しない場所へ保存する。

自動起動は保存場所を記録するため、設定後にフォルダーを移動しないでください。

## 4. プリンターをMacへ登録する

1. EW-M634TをMacと同じWi-Fiへ接続する。
2. Macの「システム設定」→「プリンタとスキャナ」を開く。
3. 「プリンタ、スキャナ、またはファクスを追加」を選ぶ。
4. EW-M634Tを選んで追加する。
5. ターミナルで`lpstat -p -d`を実行する。

`EPSON_EW_M634T_Series`のような名前と「待機中」が表示されれば準備完了です。別名なら管理画面でその名前へ変更します。

## 5. 手動で起動する

プロジェクトフォルダーへ移動し、実行します。

```sh
./scripts/start_local.sh
```

初回にネットワーク接続の許可を求められたら許可します。ターミナルは本番中閉じないでください。Macのスリープ防止も同時に動きます。

## 6. MacのIPアドレスを調べる

IPアドレスはネットワークが変わるたびに変わる可能性があります。以前の数字を決め打ちしないでください。

### システム設定

「システム設定」→「Wi-Fi」→接続中ネットワークの「詳細」を開き、「IPアドレス」を確認します。

### ターミナル

```sh
ipconfig getifaddr en0
```

何も出ない場合は`ipconfig getifaddr en1`も試します。例えば`192.168.75.237`なら参加者画面は`http://192.168.75.237:8765/`です。

### IPが変わっても同じ名前で開く

同じネットワーク内では、Macのローカルホスト名を使える場合があります。「システム設定」→「一般」→「共有」の「ローカルホスト名」が`cia-print`なら、iPadで次を開きます。

```text
http://cia-print.local:8765/
```

この方法ならIPアドレスが変わってもURLを直す必要がありません。テザリング機器によって`.local`名を解決できない場合があるため、そのときだけIPアドレス方式を使います。

## 7. iPadで開く

1. iPadをMacと同じSSIDへ接続する。
2. Safariを開く。
3. `http://MacのIPアドレス:8765/`を入力する。
4. ロック画面が表示されたら接続成功。
5. 共有ボタン→「ホーム画面に追加」で、当日はアプリのように起動できる。

IPが変わった場合、古いホーム画面アイコンは使わず、新しいIPをSafariで開いて追加し直します。

## 8. 管理画面

`http://MacのIPアドレス:8765/admin/`を開きます。

- 初期管理者PIN: `6340`
- 初期参加者パスワード: `PRINT`

管理画面で、参加者パスワード、管理者PIN、ロックへ戻る時間、連続印刷待機時間、プリンター名、固定PDFを変更できます。現在のPDFを1部再印刷することもできます。初期PINとパスワードは当日前に変更してください。

## 9. Macログイン時の自動起動

本番用Macで一度だけ実行します。

```sh
./scripts/install_autostart.sh
```

以後はMacへログインすると印刷サーバーとスリープ防止が自動起動します。ログは`logs/server.log`と`logs/server-error.log`へ保存されます。

解除は`./scripts/uninstall_autostart.sh`です。

自動起動を設定した後は、Macを再起動してログインし、iPadから画面を開けることを一度確認してください。自動起動の設定後にプロジェクトフォルダーを移動した場合は、一度解除して新しい場所で再設定します。

## 10. 当日の開始チェック

1. テザリングまたはルーターを起動する。
2. Mac・iPad・EW-M634TのSSIDが同じか確認する。
3. EW-M634TのA4用紙、インク、エラー表示を確認する。
4. Macへログインし、IPアドレスを確認する。
5. iPadでその日のIPを使って参加者画面を開く。
6. 管理画面から1部再印刷し、実際の排紙まで確認する。
7. 参加者画面で認証と受付後の自動ロックを確認する。

## 11. 故障時の切り分け

### iPadでページを開けない

- 3台のSSIDを確認する。
- URLが`https`ではなく`http`か確認する。
- IPアドレスと末尾の`:8765`を再確認する。
- MacのIPを調べ直す。
- MacのファイアウォールでPythonの受信接続を許可する。
- 公共Wi-Fiならテザリングへ切り替える。

Macで同じURLを開けるのにiPadだけ開けない場合は、ネットワーク側で端末間通信が遮断されています。Mac・iPad・プリンターを別のテザリングまたは専用ルーターへ接続し直してください。

### 画面は開くが印刷されない

- プリンターの電源、Wi-Fi、紙、インク、エラーを確認する。
- Macの「プリンタとスキャナ」で印刷キューを開き、一時停止や失敗ジョブを解除する。
- `lpstat -p -d`のプリンター名と管理画面の設定を一致させる。

### サーバーを再起動する

手動起動ならターミナルで`Control + C`を押し、再び`./scripts/start_local.sh`を実行します。自動起動ならMacを再起動してログインします。

## 12. 運用上の注意

- 受付完了はMacが印刷命令を受け付けた状態で、排紙完了の保証ではありません。
- 印刷ボタンは認証ごとに1回だけ使えます。
- パスワード認証後、60秒以内に同じiPadで印刷ボタンを押した場合だけ印刷できます。再読み込みや再接続では以前の許可を再利用できません。
- 起動時に前回から残った印刷待ちを自動で取り消します。起動前にプリンターから古い用紙が出た場合は、macOSの印刷キューも確認してください。
- 受付後60秒たっても印刷が始まらない命令は自動で取り消します。プリンターを接続し直した後に古い命令だけが印刷されることはありません。
- 初期設定では受付完了から7秒後にプリンターのホーム画面へ戻ります。
- 初期設定では15秒間の重複印刷防止があります。
- Macの蓋を閉じず、電源アダプタを接続してください。
- 本番前にMacの自動アップデートや再起動予定がないことを確認してください。

## 13. 終了

1. 印刷待ちがないことを確認する。
2. 手動起動ならターミナルで`Control + C`を押す。
3. iPadのSafariを閉じる。
4. プリンターとテザリングを停止する。
