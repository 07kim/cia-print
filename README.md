# CIA Print｜セットアップ・起動ガイド

iPadからボタンを押すだけで、EPSON EW-M634Tから指定した資料を印刷するシステムです。

**Macが印刷を中継します。** iPadからプリンターへ直接印刷する仕組みではありません。

## まず確認すること

必要な機器は次の3台です。

- **Mac：** 印刷サーバーとして使用
- **iPad：** 参加者が操作
- **EPSON EW-M634T：** 実際に印刷するプリンター

3台を同じWi-Fiに接続してください。同じネットワーク名でも、端末同士の通信が禁止されている環境では利用できません。

---

## STEP 1｜Macとプリンターを接続する（初回のみ）

1. EW-M634Tの電源を入れる。
2. Macとプリンターを同じWi-Fiに接続する。
3. Macで「システム設定」→「プリンタとスキャナ」を開く。
4. EW-M634Tが表示されているか確認する。
5. 登録されていない場合は「プリンタ、スキャナ、またはファクスを追加」から追加する。
6. Macから普通に1枚印刷できるか確認する。

**Macから印刷できない場合は、次のステップへ進まず接続を確認してください。**

## STEP 2｜CIA PrintをMacで起動する

Macで `command + space` を押し、「ターミナル」を開きます。

以下のコマンドをまとめて貼り付け、Returnキーを押してください。

```bash
cd ~/Desktop && if [ -d cia-print/.git ]; then git -C cia-print pull --ff-only; else git clone https://github.com/07kim/cia-print.git; fi && cd cia-print && ./scripts/start_local.sh
```

このコマンドは、初回にはファイルをダウンロードし、2回目以降は更新を取得して起動します。

起動すると、以下のような表示が出ます。

```text
CIA PRINT を起動しました

参加者画面  http://192.168.75.237:8765/
管理画面    http://192.168.75.237:8765/admin/
```

**表示されたIPアドレスは一例です。自分のMacに表示されたURLを使ってください。**

「起動しました」と表示されても、プリンターへの接続や印刷の成功を保証するものではありません。

## STEP 3｜iPadから接続する

1. iPadをMacと同じWi-Fiに接続する。
2. Safariを開く。
3. Macのターミナルに表示された「参加者画面」のURLを入力する。
4. パスワード入力画面が表示されたら接続成功です。

URLは `http://` から入力してください。`https://` ではありません。

## STEP 4｜印刷を確認する

初期パスワードは以下のとおりです。

| 用途 | パスワード |
|---|---|
| 参加者用 | `いんさつ` |
| 管理画面用 | `admin0000` |

まず管理画面で印刷資料とプリンターの設定を確認し、1枚テスト印刷してください。

次に参加者画面へ戻り、次の操作を試します。

1. `いんさつ` と入力する。
2. 認証が成功することを確認する。
3. 印刷ボタンを押す。
4. Macからプリンターへ命令が送られることを確認する。
5. **実際にA4用紙が排出されることを確認する。**

「受付完了」は印刷命令の受付を意味し、用紙の排出完了を保証するものではありません。

---

## 当日の起動方法

初回セットアップが終わっていれば、以下の操作だけで起動できます。

1. Mac・iPad・プリンターの電源を入れる。
2. 3台を同じWi-Fiへ接続する。
3. MacのターミナルでSTEP 2のコマンドを実行する。
4. iPadのSafariで表示されたURLを開く。
5. 1枚テスト印刷する。

印刷中はMacを起動したままにし、蓋を閉じないでください。

### 終了する

Macのターミナルで `Control + C` を押してください。

## 日本語パスワードで認証できない場合

ローカル版の初期パスワードは `いんさつ` です。旧バージョンでは、日本語の比較時にHTTP 500が発生する問題がありました。最新の `local_server.py` ではUTF-8のバイト列で比較するよう修正済みです。

発生原因、調査方法、回帰テストは [日本語パスワード認証エラーの記録](docs/unicode-password-incident-2026-11-14.md) を参照してください。Macのローカル版はGitHubの更新だけでは反映されないため、サーバー停止後にローカルコードを更新・再起動してください。

## うまく動かないとき

### ① プリンターが見つからない

Macの「システム設定」→「プリンタとスキャナ」を確認します。

ターミナルで登録状態を確認する場合：

```bash
lpstat -p -d
```

EW-M634Tが登録されていなければ追加してください。

登録されていても印刷できない場合は、プリンター本体のWi-Fi設定、電源、紙詰まり、エラー表示を確認します。

### ② iPadで画面が開かない

まずMacのSafariで次のURLを開きます。

```text
http://localhost:8765/
```

**Macでも開かない場合：** CIA Printの起動状態を確認してください。

**Macでは開くがiPadでは開かない場合：** Wi-Fi、MacのIPアドレス、macOSのファイアウォール、端末間通信の制限を確認してください。

大学のWi-Fiなどで端末同士が通信できない場合は、別のネットワークが必要です。

### ③ 画面は開くが印刷できない

Mac側で印刷キューを確認します。

```bash
lpstat -p -d
```

さらに、CIA Printで設定されているプリンター名が、Macに登録されている名前と一致するか確認してください。

初期設定のプリンター名：

```text
EPSON_EW_M634T_Series
```

別の名前で登録されている場合は、管理画面のプリンター設定を合わせてください。

### ④ GitHubで修正した内容が反映されない

Macで動かすローカル版は、GitHubを変更しただけでは自動更新されません。

CIA Printを停止してから、STEP 2のコマンドを再実行してください。

なお、Vercel上のオンライン版はデモ用であり、実機への印刷命令は送信しません。

## 運用上の注意

- 参加者のパスワード認証後、印刷操作には60秒の制限があります。
- 同じ認証で印刷できるのは1回です。
- 初期設定では連続印刷を15秒間制限します。
- 印刷受付後、初期設定では7秒後にホーム画面へ戻ります。
- 印刷前に必ず用紙・インク・Wi-Fi・プリンターのエラー表示を確認してください。
- テザリング接続では通信が不安定になる場合があります。必ず本番の環境で印刷テストを行ってください。
